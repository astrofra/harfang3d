The offline converter centers the full source bounds, rotates the coordinate system 180 degrees around X (source up axis -Y), normalizes height to 2 units, expands attributes into float4 records, and creates spatially sampled 60k/30k derivatives. These changes are made by the HARFANG tutorial; the source author does not endorse this project. RGB is retained as stored; SH lighting is not reconstructed.
